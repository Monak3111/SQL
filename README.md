# Ecommerce Analytics Dashboard

This project is a Power BI dashboard built to analyze an e-commerce business using sales, customer, product, and return data.

It helps understand overall business performance, including revenue, profit, customer behavior, product trends, and return rates.

## Data Used

The dashboard is built using the following tables:

* Orders
* Order Items
* Customers
* Products
* Returns

## Key Insights

The dashboard provides answers to questions like:

* How much revenue and profit is the business generating?
* Which product categories are performing best?
* How many customers are actively purchasing?
* What is the return rate of orders?
* What is the average order value?

## Main Metrics

* Total Revenue
* Total Orders
* Total Customers
* Average Order Value
* Profit
* Return Rate
* Customer Lifetime Value

## Visuals

* Revenue by product category (bar chart)
* Key KPI cards (Revenue, Orders, Customers, Profit)
* Customer and product performance breakdown

## Purpose

The goal of this project is to turn raw e-commerce data into simple, clear insights that help in making better business decisions.
